  # DBIlab's Website

  Visit **[dbi-lab.com](http://dbi-lab.com)** 🚀

  _Built with [Lab Website Template](https://greene-lab.gitbook.io/lab-website-template-docs)_ 

  ## Run locally

  Install Docker Desktop, then run this from the repository root:

  ```sh
  bash .docker/run.sh
  ```

  The site is served at <http://localhost:4000>. The first startup also refreshes
  publication citations from external services, so it may take a while and
  requires an internet connection.
